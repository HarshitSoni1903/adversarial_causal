# Adversarial Causal Learning

Multi-agent adversarial extension of the Multi-Round Trust Task, with causal inference over learned hidden states.

---

## Overview

This project extends the Multi-Round Trust Task (MRTT) from Dezfouli, Nock & Dayan (2020) into a two-agent adversarial setting. The MRTT is a repeated trust game in which an investor allocates money each round and a trustee decides how much to repay. Dezfouli et al. showed that a GRU-based behavioral model captures the investor's trust dynamics across rounds. We use that model as a frozen proxy for human investors and pit it against two simultaneously trained DQN trustees — one that maximizes its own reward (MAX) and one that targets equal splits (FAIR) — in a shared environment.

The key manipulation is a 2×2 design over two binary edges: **ii_edge** (whether the two investors observe each other's history) and **aa_edge** (W0 vs W1 — whether the two adversaries observe each other's actions). This lets us study how social information changes trustee exploitation and investor trust dynamics. A causal inference layer (g-computation / DML over the RNN hidden state) is used to estimate the effect of the policy edges on investor welfare while conditioning on learned behavioral states.

## Repo structure

```
config.yaml                  # All hyperparameters and experiment knobs
main.py                      # Entry point: training, evaluation, experiment matrix
analysis.R                   # Causal analysis and EDA — runs main.py or analyses existing outputs
CausalProject.r              # All the causal analysis and figure generation

game.py                      # Game loop: resolves investments, repayments, rewards per round
world.py                     # Shared state: inter-agent edges, observation routing
utils.py                     # Seed management, config loading

agents/
  investor.py                # Frozen BehavioralRNN investor (wraps checkpoints/behavioral_rnn.pt)
  adversary.py               # DQN trustee (MAX and FAIR policies)
  base.py                    # Abstract agent interface
  random_agent.py            # Baseline random trustee

models/
  behavioral_rnn.py          # GRU investor model definition
  train_behavioral.py        # Fits the RNN to MRTT data
  tune_behavioral.py         # Hyperparameter sweep for the RNN

data/
  mrtt/                      # Raw MRTT CSV files (one per condition)
  parse_mrtt.py              # Parses raw MRTT into training format
  behavioral_rnd_dataset.csv # Preprocessed RND-condition dataset

outputs/
  experiment_matrix_<ts>/    # One folder per run of --experiment-matrix
    DPG1_W0/  DPG1_W1/       # Per-condition outputs (game_log.csv, summary.json, plots)
    DPG2_W0/  DPG2_W1/
    comparison_2x2_grid.png  # Generated by analysis.R
    effect_decomposition.csv
    main_effects_table.csv
    experiment_report.md
```

## Quick start

### Python environment

No `requirements.txt` yet — install the main dependencies directly:

```bash
pip install torch numpy pandas pyyaml matplotlib
```

Python 3.10+ required (uses `str | None` union syntax).

### R environment

```r
install.packages(c("jsonlite", "ggplot2", "dplyr", "purrr", "scales"))
```

`analysis.R` will also attempt to auto-install any missing packages on first run.

### Running the full experiment

The simplest path is to run everything through `analysis.R`, which calls Python internally and then produces all analysis outputs:

```bash
Rscript analysis.R
```

To run only the Python experiment (4-condition training + eval) and skip analysis:

```bash
python main.py --experiment-matrix
```

To run analysis on a previous experiment, supply the output directory or just its timestamp:

```bash
Rscript analysis.R outputs/experiment_matrix_20260501_214233
Rscript analysis.R 20260501_214233   # timestamp shorthand
```

Other entry points:

```bash
python main.py                          # single-condition pipeline (uses config.yaml edges)
python main.py --skip-parse --skip-rnn  # skip to DQN training
python main.py --sim-only               # re-simulate latest saved weights
python main.py --smoke-test             # structural + behavioral sanity checks
```

### Outputs

Each condition folder (e.g. `outputs/experiment_matrix_<ts>/DPG1_W0/`) contains:

| File | Contents |
|---|---|
| `game_log.csv` | One row per (episode, round, agent): investment, repayment_pct, rewards, cumulative wealth |
| `summary.json` | Episode-aggregated stats: mean investor earnings, per-agent reward/repayment, training time |
| `config.yaml` | Exact config used for that condition |
| `training_curves.png` | Smoothed training returns and eval snapshots |
| `figure5c_mean_repayment.png` | Mean repayment % by round (replication target) |

`analysis.R` writes aggregate outputs to the matrix root: `comparison_2x2_grid.png`, `effect_decomposition.csv` (bootstrap 95% CIs), `main_effects_table.csv`, `experiment_report.md`, and several EDA plots.

### Key config knobs

All live in `config.yaml`:

| Key | What it controls |
|---|---|
| `edges.ii_edge` | `0` = investors isolated, `1` = investors observe each other |
| `edges.aa_edge` | `0` = W0 (adversaries isolated), `1` = W1 (adversaries observe each other) |
| `game.dyads[*].trustee.type` | `max` or `fair` — adversary objective |
| `adversary.training_episodes` | Total DQN training episodes per condition (default 50 000) |
| `adversary.matrix_eval_episodes` | Evaluation episodes per condition in the experiment matrix (default 1 000) |
| `game.max_rounds` | Rounds per episode (default 10, matching the original MRTT) |
| `game.endowment_per_investor` | Investor endowment per round (default 20) |
| `seed` | Global random seed |

## Reproducing the Dezfouli replication

Set `edges.ii_edge: 0` and `edges.aa_edge: 0` (the defaults), then run:

```bash
python main.py --skip-parse --skip-rnn --experiment-matrix
```

Look at `DPG1_W0/figure5c_mean_repayment.png` for agent `a1` (MAX trustee). The target pattern from Figure 5D of Dezfouli et al. is high repayment in round 0 (~75%) declining to below 30% by round 9 — the adversary learns to exploit early trust and defect late. The smoke-test flag also checks this automatically and reports PASS/WARNING.
